# Foundations ECG Lab — Week 1 starter

A static, case-based ECG education website. The current version includes four cases from Unit 5: SVT, AF with RVR, atrial flutter, and MAT.

## Publish with GitHub Pages

1. Make a **public** GitHub repository named `foundations-ecg-lab`.
2. Upload the **contents** of this folder (not the containing folder or ZIP file): `index.html`, `style.css`, `script.js`, `cases.json`, and the `assets` folder.
3. Go to **Settings → Pages → Build and deployment → Deploy from a branch**. Choose `main` and `/(root)` then Save.
4. Open the published link displayed in Settings → Pages.

## Weekly release rule

**Never upload future-week pages, images, or JSON into the public repository before release.** The source code and asset URLs are public. Keep unreleased weeks in local files or a separate private repository, then add each lesson when it is time. You can link it from the same home page. Simply putting a lock icon on an uploaded lesson is not access control.

## Edit a case

Open `cases.json` in GitHub's editor. Change the text while keeping JSON syntax valid. ECG images live in `assets/`.

## Important

No user authentication, grading backend, or tracking is included. Obtain permission to redistribute the source ECG images/slides before making a public website. Confirm teaching guidance against current AHA ACLS, AF guidelines, and local policy.
